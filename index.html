🛰️ Permissão de GPS

Para o iPhone liberar sua localização, siga estes passos:

  1. Toque em "Permitir" quando o aviso do Safari aparecer
  2. Se negou antes: Ajustes → Safari → Localização → Permitir
  3. Verifique também: Ajustes → Privacidade → Serviços de Localização → Safari → Ao Usar o App
  4. O site precisa estar em HTTPS (Safari bloqueia GPS em HTTP)
